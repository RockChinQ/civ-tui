# civ-tui 项目状态

## 已完成功能

### 核心架构
- [x] Go + Bubble Tea (Elm Architecture) TUI 框架搭建
- [x] Model-Update-View 渲染循环
- [x] 主入口 (Alt Screen 模式)
- [x] 游戏状态管理 (`game/game.go`)

### 地图系统
- [x] 60x35 固定大小网格地图
- [x] 基于随机种子的程序化地图生成
- [x] 9 种地形类型 (海洋、海岸、草地、平原、丘陵、山脉、森林、沙漠、苔原)
- [x] 每种地形有独立的食物/生产力/金币产出和移动力消耗
- [x] 地图边缘偏向生成海洋/海岸 (大陆式布局)
- [x] 战争迷雾系统 (双层可见性: Revealed / Visible)
- [x] 视野范围计算 (曼哈顿距离 = 3)
- [x] 每回合重新计算可见性

### 文明系统
- [x] 双文明对战 (玩家: 罗马帝国 vs AI: 蒙古)
- [x] 文明属性追踪 (金币、科研点、已研究科技、存活状态)
- [x] 初始金币 (10)

### 单位系统
- [x] 7 种单位类型 (开拓者、斥候、战士、弓箭手、枪兵、剑士、骑兵)
- [x] 每种单位有独立的 HP、攻击、防御、移动力、生产成本
- [x] 单位移动 (受地形移动力消耗影响)
- [x] 单位等待 (跳过回合)
- [x] 单位循环选择 (N 键)
- [x] 不可通行地形的自动位置调整

### 战斗系统
- [x] 近战战斗 (移动到敌方单位格子触发)
- [x] 同时伤害计算 (攻击 + 随机 0~2)
- [x] 双方均可在同一次战斗中阵亡
- [x] 攻城战 (攻击敌方城市)
- [x] 城市占领 (城市 HP 归零后转换所有权)

### 城市系统
- [x] 开拓者建城 (消耗单位)
- [x] 城市间最小距离限制 (曼哈顿距离 >= 3)
- [x] 命名系统 (罗马城市名 / 蒙古城市名)
- [x] 城市属性 (人口、食物、生产力、HP、防御)
- [x] 人口增长 (食物积累 >= 人口 * 10)
- [x] 生产队列 (逐回合积累生产力直至完成)
- [x] 产出计算 (基础 + 地形 + 建筑加成)
- [x] 5 种建筑 (谷仓、兵营、市场、图书馆、城墙)

### 科技树
- [x] 11 项科技，含前置依赖链
- [x] 科技可用性判定 (前置科技检查)
- [x] 每回合科研进度累积
- [x] 科技研究菜单 (T 键)

### AI 系统
- [x] 自动科技研究 (随机选择可用科技)
- [x] 开拓者 AI (满足距离条件时建城，否则随机移动)
- [x] 军事 AI (寻找最近玩家单位/城市，贪心逼近)
- [x] 城市生产 AI (根据单位数量选择生产战士/弓箭手/枪兵)

### 胜利条件
- [x] 统治胜利 (消灭所有敌方单位和城市)
- [x] 科技胜利 (研究全部 11 项科技)
- [x] 平局 (达到 200 回合)
- [x] 失败判定 (玩家失去所有单位和城市)

### TUI 界面
- [x] 地图面板 (可滚动视口，光标边缘自动滚动)
- [x] 信息面板 (选中单位信息、可用操作、科研进度)
- [x] 消息面板 (最近 8 条游戏消息)
- [x] 顶部状态栏 (回合数、金币、科研、文明名)
- [x] 256 色终端调色板，地形/单位着色
- [x] 战争迷雾渲染 (░ 字符 + 暗灰色)
- [x] 光标 (反转色)、选中单位 (黄底黑字)
- [x] 建造菜单 / 科技菜单 (覆盖层)
- [x] 帮助界面 (? 键)
- [x] 游戏结束界面
- [x] 键盘操作 (方向键/hjkl、F/W/N/B/T/Enter/Esc/Q)

## 待办事项 (已知问题与缺失功能)

### 已知 Bug / 技术债务
- [ ] 城墙建筑的 `DefBonus` 字段已定义但未在攻城计算中使用
- [ ] 阵亡单位仅标记 HP=0 而未从切片中移除，内存无限增长
- [ ] 自实现 `itoa()` 函数，应使用 `strconv.Itoa()`
- [ ] AI 硬编码目标为 CivID==1，无法扩展到多文明场景
- [ ] 零测试覆盖率，无任何 `*_test.go` 文件

### 缺失的核心游戏机制
- [ ] **科技效果**: 科技研究无实际游戏效果 (不解锁单位/建筑/加成)，仅用于科技胜利判定
- [ ] **单位解锁**: 所有单位从游戏开始即可生产，无科技前置要求
- [ ] **建筑解锁**: 所有建筑从游戏开始即可建造，无科技前置要求
- [ ] **单位治疗**: 受损单位无法恢复 HP
- [ ] **地形改良**: 无工人单位、无农场/矿山等改良设施
- [ ] **资源系统**: 无战略资源、奢侈资源
- [ ] **外交系统**: 无和平/战争状态切换、无贸易、无外交选项
- [ ] **多文明支持**: 固定为 2 个文明，无法扩展
- [ ] **地图生成质量**: 纯随机生成 (椒盐噪声)，无 Perlin 噪声或连贯大陆
- [ ] **远程攻击**: 弓箭手等单位无远程攻击能力
- [ ] **海军单位**: 无法进入海洋/海岸格
- [ ] **存档/读档**: 游戏无法保存和加载
- [ ] **城市管理**: 无公民分配、无专家系统
- [ ] **文化/宗教/政策**: 完全缺失
- [ ] **奇观**: 无世界奇观和国家奇观
- [ ] **地形特征**: 无河流、无湖泊
- [ ] **城市名耗尽处理**: 城市名列表用完后无备用方案
- [ ] **单位经验/升级**: 无经验值积累和单位晋升系统
- [ ] **维护费用**: 单位和建筑无维护费
- [ ] **幸福度/宜居度**: 完全缺失
- [ ] **大地图支持**: 固定 60x35，无地图大小选项

### 缺失的界面功能
- [ ] **城市详情界面**: 无法查看城市完整信息和管理界面
- [ ] **科技树可视化**: 无科技树图形展示，仅有列表选择
- [ ] **小地图/总览**: 无缩略地图
- [ ] **动画/过场**: 无战斗动画、无回合过渡效果
- [ ] **音效**: 无任何音频反馈
- [ ] **鼠标支持**: 仅键盘操作
- [ ] **配置选项**: 无游戏设置界面 (难度、地图大小等)
- [ ] **多语言**: 所有文本硬编码英文

### 缺失的基础设施
- [ ] **单元测试**: 无任何测试
- [ ] **CI/CD**: 无持续集成配置
- [ ] **构建脚本**: 无 Makefile 或构建自动化
- [ ] **发布流程**: 无版本管理和发布配置
- [ ] **项目文档**: 仅有极简 README
