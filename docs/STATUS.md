# civ-tui 项目状态

> 最后更新: 2026-04-07

## 已完成功能

### 核心架构
- [x] Go + Bubble Tea (Elm Architecture) TUI 框架搭建
- [x] Model-Update-View 渲染循环
- [x] 主入口 (Alt Screen 模式)
- [x] 游戏状态管理 (`game/game.go`)
- [x] 游戏逻辑与 TUI 分离 (`game/` 无 TUI 依赖)
- [x] 代码模块化拆分 (tui/ 8 个文件, game/ 5 个文件, i18n/ 3 个文件)

### 国际化 (i18n)
- [x] 双语支持 (English / 简体中文)
- [x] 翻译系统: T() / Tf() 函数, 英文字符串作为 key
- [x] 中文翻译映射表 (~130 条翻译)
- [x] 全面覆盖: 菜单、信息面板、消息、战斗日志、实体名称 (地形/单位/建筑/科技/改良/文明)
- [x] 系统语言自动检测 (检查 LANG / LC_ALL / LANGUAGE 环境变量)
- [x] 语言设置持久化 (`~/.civ-tui/config.json`)
- [x] 双语帮助文本 (? 键)

### 地图系统
- [x] 可配置地图大小 (小: 40x25, 中: 60x35, 大: 80x48)
- [x] 分形噪声程序化地图生成 (4 层叠加 + 双线性插值)
- [x] 大陆式布局 (边缘偏向生成海洋)
- [x] 9 种地形类型 (海洋、海岸、草地、平原、丘陵、山脉、森林、沙漠、苔原)
- [x] 每种地形有独立的食物/生产力/金币产出、移动力消耗和防御加成
- [x] 战争迷雾系统 (双层可见性: Revealed / Visible)
- [x] 视野范围计算 (曼哈顿距离 = 3)
- [x] 每回合重新计算可见性
- [x] 4 种地形改良 (农场、矿山、道路、伐木场)
- [x] 改良需要多回合建造
- [x] 地图坐标标签 (X 轴顶部, Y 轴左侧, 每 5 格标注)

### 文明系统
- [x] 支持 1~4 个 AI 文明
- [x] 5 个可用文明 (罗马、蒙古、埃及、中国、希腊)
- [x] 文明属性追踪 (金币、科研点、已研究科技、存活状态)
- [x] 初始金币 (10)
- [x] 文明间外交关系 (和平/战争)

### 单位系统
- [x] 8 种单位类型 (开拓者、斥候、战士、弓箭手、枪兵、剑士、骑兵、工人)
- [x] 每种单位有独立的 HP、攻击、防御、移动力、生产成本
- [x] 单位移动 (受地形移动力消耗影响, 4 方向)
- [x] 单位等待 (跳过回合, 恢复 1 HP)
- [x] 单位循环选择 (N 键, 包括单位和城市)
- [x] 不可通行地形的自动位置调整 (单位生成时)
- [x] 科技解锁单位生产 (弓箭手←Archery, 枪兵←Bronze Working, 剑士←Iron Working, 骑兵←Horseback Riding)
- [x] 工人单位建造地形改良 (I 键)
- [x] 经验值和等级系统 (5 XP = 升级, 攻击+1)
- [x] 选中单位跨回合保持

### 移动与寻路
- [x] 移动范围可视化 (绿色高亮 BFS 洪水填充, 考虑地形移动消耗)
- [x] 移动目标设置 (G 键进入 Goto 模式, 选择目的地)
- [x] Dijkstra 自动寻路 (计算最短路径)
- [x] 每回合自动移动 (有目的地的单位按路径自动前进)
- [x] 目的地标记 (紫色高亮显示目标格)
- [x] 取消目的地 (X 键)
- [x] 智能 N 键跳过 (忙碌/有目的地的单位不参与循环)
- [x] 单位状态颜色: 黄色=选中, 橙色=建造中, 青色=自动移动中
- [x] 遭遇战斗自动取消目的地

### 战斗系统
- [x] 近战战斗 (移动到敌方单位格子触发)
- [x] 同时伤害计算 (攻击 + 随机 0~2)
- [x] 地形防御加成 (丘陵/森林 +25%)
- [x] 远程攻击 (弓箭手, 射程 2, R 键进入射击模式)
- [x] 远程攻击不受反击伤害
- [x] 攻城战 (攻击敌方城市)
- [x] 城市占领 (城市 HP 归零后转换所有权)
- [x] 战斗经验值奖励
- [x] 战斗消息包含文明名和坐标: `[罗马帝国] 战士 攻击 [蒙古] 弓箭手 (15,8) → 击杀!`

### 城市系统
- [x] 开拓者建城 (消耗单位, F 键)
- [x] 城市间最小距离限制 (曼哈顿距离 >= 3)
- [x] 各文明独立城市命名系统 + 备用 "City N" 命名
- [x] 城市属性 (人口、食物、生产力、HP、防御)
- [x] 人口增长 (食物积累 >= 人口 * 10)
- [x] 生产队列 (逐回合积累生产力直至完成)
- [x] 产出计算 (基础 + 地形 + 建筑 + 改良加成)
- [x] 5 种建筑 (谷仓、兵营、市场、图书馆、城墙), 含科技前置要求
- [x] 建筑维护费用
- [x] 城市详情界面 (V 键在己方城市上打开)
- [x] 信息面板显示城市生产状态 (光标在城市上时显示当前生产项)

### 单位治疗
- [x] 驻扎在己方城市的单位每回合恢复 2 HP
- [x] 不在城市中的单位等待后恢复 1 HP

### 科技树
- [x] 11 项科技，含前置依赖链
- [x] 科技可用性判定 (前置科技检查)
- [x] 每回合科研进度累积
- [x] 科技研究菜单 (T 键)
- [x] 科技解锁单位和建筑生产
- [x] 科技菜单显示解锁内容

### AI 系统
- [x] AI 科研优先级 (优先研究能解锁单位的科技)
- [x] 开拓者 AI (满足距离条件时建城，否则随机移动)
- [x] 军事 AI (寻找最近敌方单位/城市，贪心逼近)
- [x] 城市生产 AI (根据单位数量和科技选择生产项目)
- [x] AI 外交决策 (基于军力对比和损失)

### 外交系统
- [x] 和平/战争状态
- [x] 宣战/求和机制 (D 键)
- [x] 外交界面

### 胜利条件
- [x] 统治胜利 (消灭所有敌方单位和城市)
- [x] 科技胜利 (研究全部 11 项科技)
- [x] 平局 (达到 200 回合)
- [x] 失败判定 (玩家失去所有单位和城市)

### TUI 界面
- [x] 地图面板 (可滚动视口，光标边缘自动滚动)
- [x] 地图坐标标签 (X 轴顶部每 5 格, Y 轴左侧每 5 格)
- [x] 可达格子绿色高亮 / 目的地紫色标记 / 忙碌单位橙色 / 移动中单位青色
- [x] 信息面板 (选中单位信息、可用操作、科研进度、城市生产状态)
- [x] 消息面板 (最近 8 条游戏消息)
- [x] 顶部状态栏 (回合数、金币及每回合收入、科研、文明名)
- [x] 小地图 (信息面板底部)
- [x] 256 色终端调色板，地形/单位着色
- [x] 战争迷雾渲染 (░ 字符 + 暗灰色)
- [x] 光标 (反转色)、选中单位 (黄底黑字)
- [x] 远程攻击目标高亮
- [x] 建造菜单 / 科技菜单 (居中弹出框)
- [x] 地形详情检查 (V 键, 显示地形/改良/单位/城市完整信息)
- [x] 帮助界面 (? 键, 双语)
- [x] 主菜单 (新游戏 / 加载 / 设置 / 退出)
- [x] 新游戏设置界面 (地图大小、AI 数量、难度)
- [x] 设置界面 (语言选择)
- [x] 游戏结束界面
