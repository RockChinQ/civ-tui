# civ-tui 项目计划

> 目标：在终端中实现一个基本可玩的 Civilization 风格回合制策略游戏。

## 设计原则

1. **渐进式实现** -- 每个阶段交付可玩的版本，逐步增加深度
2. **TUI 优先** -- 所有功能设计都围绕终端界面的约束和优势
3. **简洁优于完整** -- 不追求还原完整 Civ，而是抓住核心乐趣
4. **可测试** -- 游戏逻辑与 TUI 分离，核心逻辑有测试覆盖
